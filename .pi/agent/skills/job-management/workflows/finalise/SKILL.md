# Finalise application

Read [the shared workflow](../../references/WORKFLOW.md) and `Professional Voice Guide.md`.

## Contract

**Requires:** advertisement/JDF, repository, and all required drafts.  
**Produces:** review findings, corrected working drafts with approval, and optional submitted snapshot.  
**Next:** submission or archive.

## Steps

1. Request the advertisement/JDF, all required drafts, submission instructions, deadline, and output location.
2. Verify every material claim against `Work Achievements Repository.md`.
3. Check every requirement has evidence and that responsibilities, achievements, metrics, titles, dates, technologies, ownership, and delivery status agree across documents.
4. Apply the voice guide: identify generic phrasing, repeated examples, unnatural keyword matching, and wording needing the user's personal rewrite.
5. Check document-specific constraints, spelling, grammar, filenames, and requested formats.
6. Present findings before editing. Apply changes only with user approval.
7. Ask whether the application has actually been submitted. Only after confirmation, preserve the final files unchanged under `submitted_applications/<organisation>_<role>/`; never overwrite an existing snapshot.

Completion: no unresolved factual conflict is hidden, every required document is accounted for, and archival status matches reality.
