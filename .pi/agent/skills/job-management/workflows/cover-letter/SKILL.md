# Cover letter

Read [the shared workflow](../../references/WORKFLOW.md) and `Professional Voice Guide.md`.

## Contract

**Requires:** advertisement, repository, fit analysis, and the user's real reason for applying.  
**Produces:** evidence outline, then user-confirmed letter draft.  
**Next:** human edit and finalise.

## Steps

1. Request the advertisement, organisation, recipient if known, length/format, deadline, output path, and the user's plain-language reason for applying.
2. Ask for verified organisation context or research permission when company-specific claims are needed.
3. Load the fit analysis. If missing, run `../fit-analysis/SKILL.md` first.
4. Select two examples that address the employer's needs and complement rather than repeat the resume's strongest bullets.
5. Produce a factual outline for the opening, two body paragraphs, and restrained closing. Mark organisation-specific facts and personal motivation for user input.
6. Obtain the user's edits or confirmation, then draft using the voice guide.
7. Review for unsupported enthusiasm, generic claims, repeated resume content, ownership, and length.

Completion: motivation is supplied by the user, organisation claims are verified, and the letter sounds like a person explaining fit rather than application marketing copy.
