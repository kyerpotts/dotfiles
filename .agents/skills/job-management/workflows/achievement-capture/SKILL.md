# Capture job evidence

Read [the shared workflow](../../references/WORKFLOW.md), then locate and read the relevant role and skills sections of `Work Achievements Repository.md`.

## Contract

**Requires:** the user's account and the repository.  
**Produces:** a user-confirmed repository update.  
**Next:** fit analysis or no further action.

## Steps

1. Extract role, date, baseline responsibility, problem, scale, constraints, personal actions, collaborators, technologies, outcome, metric, and delivery status.
2. Ask one grouped set of questions only for missing facts that would materially change the entry.
3. Compare with existing evidence and surface duplicate or conflicting facts.
4. Show the exact proposed Context, Actions, Outcomes, and skills changes.
5. Obtain explicit confirmation, then edit only `Work Achievements Repository.md`.
6. Re-read the changed section and report the heading updated.

Record factual evidence rather than application prose. Distinguish led, implemented, contributed, designed, and proposed. Leave unknown facts absent.
