# Tailored resume

Read [the shared workflow](../../references/WORKFLOW.md), `Generic Resume Template.md`, and `Professional Voice Guide.md`.

## Contract

**Requires:** advertisement/JDF, repository, and fit analysis.  
**Produces:** ATS-readable working resume plus personalisation and fact-check notes.  
**Next:** human edit, cover letter, or finalise.

## Steps

1. Gather the target role, organisation, length, format, output path, and roles to include or exclude.
2. Load an existing fit analysis. If none exists, run the process in `../fit-analysis/SKILL.md` first.
3. Select evidence for requirement coverage. For each role, separate:
   - concise base responsibilities showing day-to-day operating experience;
   - selected achievements showing improvement, initiative, leadership, difficult problem-solving, or measurable impact.
4. Draft using `Generic Resume Template.md`. Use plain headings and a single-column ATS-readable structure.
5. Apply the voice guide without turning factual bullets into slogans.
6. Return or save:
   - the resume draft;
   - wording the user should personalise;
   - remaining fact checks and requirement gaps.

Completion: important requirements have visible evidence, routine experience is distinct from additional value, and every claim traces to the repository.
