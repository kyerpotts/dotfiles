# Selection criteria

Read [the shared workflow](../../references/WORKFLOW.md) and `Professional Voice Guide.md`.

## Contract

**Requires:** exact criteria/JDF, repository, and fit analysis.  
**Produces:** evidence outline, then user-confirmed prose.  
**Next:** human edit and finalise.

## Steps

1. Request the complete criteria/JDF, word or page limits, required response format, deadline, and output path.
2. Load the fit analysis. If missing, run `../fit-analysis/SKILL.md` first.
3. For each criterion select one primary example; add supporting examples only when the wording requires breadth.
4. Produce an evidence outline containing:
   - what the criterion tests;
   - base-responsibility evidence;
   - strongest achievement;
   - situation and constraint;
   - personal actions and decisions;
   - stakeholders;
   - measurable result and delivery status;
   - missing facts.
5. Ask the user to correct facts, add context, and paraphrase wording that should sound personal.
6. After confirmation, convert the outline into prose using the voice guide. Preserve the user's wording where it works.
7. Review coverage, repetition, ownership, status, and length.

Completion: every criterion is answered directly with traceable evidence and the human editing gate has occurred before final prose.
