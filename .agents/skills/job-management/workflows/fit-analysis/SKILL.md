# Job fit analysis

Read [the shared workflow](../../references/WORKFLOW.md).

## Contract

**Requires:** complete advertisement or JDF and `Work Achievements Repository.md`.  
**Produces:** requirement map, evidence strengths, gaps, questions, and application recommendation.  
**Next:** evidence capture, resume, selection criteria, or cover letter.

## Steps

1. Request the advertisement/JDF as text, path, document, or URL. Ask for role, organisation, deadline, and any application instructions not contained in it.
2. Read the source completely and extract essential criteria, desirable criteria, duties, seniority signals, domain needs, values, and document constraints.
3. Read the achievement repository and map every requirement to:
   - base-responsibility evidence;
   - achievement evidence showing additional value;
   - exact metric, scale, technology, or stakeholder evidence;
   - strength: strong, partial, or gap.
4. Identify contradictions, claims requiring confirmation, and requirements supported only by familiarity.
5. Recommend strong apply, apply with caveats, or skip. Select the three anchor achievements and explain the material gaps.
6. Save the map when an output location has been agreed; otherwise return it in chat.

Completion: every explicit requirement is accounted for and no gap is hidden by generic wording.
