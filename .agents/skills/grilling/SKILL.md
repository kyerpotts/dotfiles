---
name: grilling
description: Grill the user relentlessly about a plan, decision, or idea. Use when the user wants to stress-test their thinking, or uses any 'grill' trigger phrases.
---

Interview the user relentlessly until you reach a shared understanding. Map this as a **design tree**: every decision branches into the decisions that hang off it.

Work the tree in **rounds**. The **frontier** is every decision whose prerequisites are already settled — the questions you can ask _now_ without guessing at answers you haven't heard yet. Ask frontier questions with the structured question tool, putting the recommended option first and labeling it `(Recommended)`. Keep every question header under 16 characters (15 characters maximum) before calling the tool. Use the tool's descriptions and, when useful, prose immediately before the tool call to explain examples and trade-offs. Then wait for the user's answers before the next round.

The question tool accepts at most four questions per call. When the frontier is larger, ask the four most prerequisite-heavy questions and carry the remaining independent questions into the next round; never stack question-tool calls without waiting for answers. If the tool is unavailable, use numbered questions with a recommended answer for each.

Each round the user answers reshapes the tree — settled decisions push the frontier outward and unblock questions that depended on them. Recompute the frontier and ask the next round. A question whose answer depends on another question still open in this round belongs to a _later_ round, not this one.

Finding _facts_ is your job, never the user's. When a frontier question needs a fact from the environment (filesystem, tools, etc.), dispatch a sub-agent to find it — don't ask the user for anything you could look up yourself. Don't block on it: a running exploration is an unsettled prerequisite, so only the questions downstream of it wait for the sub-agent to report — ask the rest of the frontier now. The _decisions_ are the user's — put each to them and wait.

The session is done when the frontier is empty: every branch of the design tree visited, nothing left silently assumed. Do not act on it until the user confirms you have reached a shared understanding.
